# Quick Scan Workflow

// turbo-all

## Adımlar

1. Projeyi tara:
```
scan_project(path="<PROJECT_PATH>")
```

2. Proje özetini al:
```
get_project_summary(path="<PROJECT_PATH>")
```

3. Mimari diyagram üret:
```
generate_architecture_diagram(path="<PROJECT_PATH>")
```

4. Sonuçları kısa bir rapor olarak sun.
